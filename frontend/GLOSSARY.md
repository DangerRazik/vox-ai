# Vox AI

Интерфейс системы анализа качества звонков колл-центра. Доменная терминология соответствует backend Vox AI.

## Язык предметной области

**Заказчик**:
Организация, использующая Vox AI для анализа звонков своих сотрудников. Её записи и отчёты отделены от данных других заказчиков.
_Не использовать_: клиент (для организации-заказчика).

**Команда Vox AI**:
Команда, которая в тестовой версии создаёт и настраивает стримы для заказчиков и вручную запускает обработку батчей.

**Стрим**:
Последовательность транскрибации записи звонка, обработки транскрипции и анализа результатов с фиксированными настройками, словарями и базой знаний. Принадлежит заказчику; любые изменения означают стрим с новым идентификатором.

**Батч**:
Группа принятых записей одной загрузки, связанная с одним заказчиком и одним стримом. После завершения загрузки состав группы неизменяем.

**Идентификатор загрузки**:
Обозначение исходной загрузки, сохраняемое при её повторе после сбоя. Новый идентификатор обозначает независимую загрузку и новый батч.

**Дубликат файла**:
Файл с содержимым, совпадающим с уже принятой аудиозаписью того же батча. Внутри батча соответствует существующей записи.

**Ошибка загрузки**:
Причина, по которой переданный файл не принят как запись звонка.

**Ошибка обработки записи**:
Неуспешное выполнение стрима для принятой записи звонка.

**Ошибка обработки батча**:
Сбой, препятствующий завершению обработки всего батча или целостному сохранению его результатов.

**Сводный отчёт по батчу**:
Итоговое представление результатов анализа записей одного батча после завершения их обработки. Используется для изучения группы звонков и сравнения батчей одного стрима.

**Отчёт по звонку**:
Подробное представление результатов анализа одной записи звонка по выбранному стриму.

**Сравнение батчей**:
Сопоставление показателей нескольких выбранных завершённых батчей одного стрима.

**Сотрудник**:
Участник разговора, представляющий колл-центр, работу которого оценивает система.

**Клиент**:
Участник разговора, общающийся с сотрудником колл-центра.

**Транскрипция**:
Текст разговора, представленный репликами с временными границами и распределением между ролями сотрудника и клиента.

**Итоговая оценка звонка**:
Сумма оценок выбранных критериев; максимум равен их количеству. При критическом нарушении становится 0, если критерий 5.2 и правило обнуления включены в стриме. Старые стримы используют все 11 критериев. Отключённые критерии не оцениваются и не входят в итог.
