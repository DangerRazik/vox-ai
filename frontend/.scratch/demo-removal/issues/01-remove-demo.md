# Удаление демонстрационного режима

Triage: ready-for-agent
Status: implemented

По запросу пользователя изменяется только рабочий frontend в vox-ai-workspace. Репозиторий vox-ai-github, remotes, backend и рабочая БД не изменяются.

- Удалены условные каталоги, отчёты, источники, панели имитации и маршруты.
- Общие формы и отчёты используют REST без переключателя demo.
- Главная страница открывает подключение. Ошибки API не подменяются данными.
- Старые браузерные сценарии имитации удалены; проверки компонентов и REST сохраняются.
- Исторические документы отмечены как история; README описывает текущий режим.

Проверено: Angular typecheck, production build с /vox/, 69 тестов компонентов, 45 браузерных REST-сценариев, 3 сценария с настоящим backend на временной БД (вход/изоляция, ZIP, административные операции). Живой сценарий опубликованных отчётов требует отдельного подготовленного fixture и не запускался.
