# 01: Общий локальный запуск Vox AI

Status: ready-for-agent
Implementation: complete

Запрошено пользователем 2026-10-09.

- `npm start` из frontend запускает API, обработчик и фронт.
- Проверка Python, npm/backend-зависимостей, `.env`, ffprobe, портов и worker locks.
- Используются существующие настройки и постоянные данные backend.
- Ошибки окружения объясняются без вывода ключей.
- Подписи логов `[API]`, `[Обработчик]`, `[Фронт]`.
- Ctrl+C останавливает все собственные процессы. При отказе службы остальные останавливаются.
- Уже запущенные посторонние процессы не завершаются.
- Отдельный запуск Angular сохраняется как `start:frontend`, используется браузерными тестами.
- Исходный код backend и пользовательские изменения шаблонов не меняются.

## Приёмка

Реальные процессы API/worker/Angular с временной SQLite, тестовыми ключами
и отдельными портами: API через прокси, остановка, освобождение портов и locks,
отказ worker, остановка во время старта, занятый порт, отсутствующие .env/Python,
ошибочный ключ без раскрытия значения, второй worker. Whisper/LLM не вызываются.

Проверено на Windows: семь проверок запуска с настоящими процессами (включая
`npm start`), десять браузерных проверок через отдельный `start:frontend`,
typecheck и production-сборка. Проверка текущего окружения `--check` проходит
без запуска worker и без изменения записей БД. Использованные тестовые службы
остановлены; временные данные остаются в игнорируемой `.scratch/runtime/`.

Проверено завершение процесса общего запуска после Ctrl+C: stdin освобождается,
Python получает прерывание через управляющий канал, дерево Angular завершается.
Пользовательские изменения удаления подписи sidebar и backend/.env.example
не включаются в коммит этой задачи.
