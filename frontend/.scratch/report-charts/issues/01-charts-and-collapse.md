# Графики отчётов и сворачивание разбора звонка

Status: ready-for-agent
Implementation: complete

Последующее уточнение 2026-10-09: график сравнения удалён вместе с компонентом
и стилями. При успешном ответе список выбора и кнопка сравнения скрываются;
кнопки «Изменить выбор» нет. При сбое форма сохраняется для повтора, при смене
стрима или новом открытии страницы снова доступен выбор батчей. Исходные пункты
ниже описывают первую версию.

- [x] Горизонтальные столбики средних оценок выбранных критериев в отчёте батча.
- [x] По уточнению пользователя убрать дублирующую таблицу и назвать график «Средние оценки критериев».
- [x] График средних итогов выбранных батчей одного стрима в сравнении.
- [x] График упорядочен по времени загрузки; таблица сохраняет порядок выбора.
- [x] Отсутствующие оценки отображаются как «Нет данных», разрывают линию и не заменяются нулём.
- [x] Сворачиваются критерии, транскрипция, метрики, база знаний и рекомендации.
- [x] Итог и критическое нарушение остаются видимыми.
- [x] Предпочтения блоков сохраняются в браузере; недоступность storage не ломает отчёт.
- [x] Проверки компонентов, клавиатуры, перезагрузки и узкого экрана; production build.

Графики отображают существующие результаты API/демо, без новых запросов анализа.
Шкала критериев — 0–1, итогов — число включённых критериев (для старого контракта 11).
Точки на графике сравнения идут через равные интервалы по порядку даты; номера
соответствуют списку под графиком с именами, датами и значениями.
В localStorage сохраняется только expanded/collapsed для каждого типа блока.

Проверка: 72 компонентных теста, 24 браузерных сценария, сборка Angular;
скриншоты отчёта, сравнения и разбора проверены на компьютере и узком экране.
