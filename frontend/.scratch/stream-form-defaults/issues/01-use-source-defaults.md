и публичный backend REST API. В живой проверке модели не вызываются.

Проверки завершены:

- Frontend: `npm run typecheck`, `npm run build`, `npm test` — 67 проверок компонентов.
- Браузер: полный набор — 130 passed, 4 opt-in live skipped.
- Отдельная живая административная приёмка — passed: источник Whisper,
  его редактирование и сохранение, создание/копирование, прежний снимок,
  ручной старт, запрет занятого удаления, каскадное удаление и права заказчика.
- Backend: 87 проверок, из них 9 opt-in/live/load пропущены;
  REST-проверка источников параметров, административных прав и сохранности
  после пересоздания приложения выполнена на временной SQLite и файлах.

Изменения проверены вручную: frontend отправляет только редактируемые параметры,
не копирует скрытые настройки исходного стрима в новый запрос; сервер фиксирует
полный снимок и не переопределяет старые стримы во время обработки.
Запущенный пользователем backend и его постоянная БД не изменялись тестами.
Для использования изменений нужен обычный перезапуск API.
