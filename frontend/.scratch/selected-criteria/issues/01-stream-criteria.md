# Выбор критериев оценки при создании стрима

Status: ready-for-agent
Implementation: complete

Уточнение 2026-10-09: пользователь отменил выбор критериев в форме. Чекбоксы
удалены, возвращён раскрываемый фиксированный список. Все новые стримы, включая
создание на основе старого подмножества, отправляют полный набор из 11 критериев.
Старые снимки, отчёты и совместимость контракта сохранены. Конструктор критериев
будет отдельной задачей; прежние пункты ниже описывают исходную реализацию.

Решение: отключённые критерии исключаются из оценки; максимум равен числу выбранных.
Не менее одного критерия, все 11 включены по умолчанию. Старые стримы не изменяются.
Выбор сохраняется при создании на основе стрима. Отключение 5.2 отключает обнуление.

- [x] Чекбоксы в форме, валидация пустого набора, блокировка и копирование.
- [x] Снимок backend, выбранный чек-лист LLM, расчёт и сводки.
- [x] Отчёты, список батчей, сравнение и демо с переменным максимумом.
- [x] Компонентные, браузерные и REST-проверки; сохранность после перезапуска.

Проверки: 67 компонентных тестов, сборка, 50 браузерных сценариев и отдельная
живая проверка формы с временным backend/SQLite (без Whisper/LLM).
Backend: 93 проверки прошли, 9 opt-in проверок внешних ресурсов пропущены.
Публикация выбранного набора и сравнение после перезапуска проверены через REST;
в тесте обработки заменены только границы транскрибации/ролей и ответа модели.

Backend: docs/adr/0005-selected-stream-criteria.md заменяет обязательный набор из ADR 0002.
Контракт: `config.enabled_criteria` — массив уникальных известных ID, непустой;
отсутствие поля означает все 11. `criteria` содержит выбранные критерии.
Результаты и сводки содержат `max_total`; отсутствующие критерии не показываются.
