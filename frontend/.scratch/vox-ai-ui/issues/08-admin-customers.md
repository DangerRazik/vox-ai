**What to build:** Команда Vox AI видит организации, создаёт демонстрационного заказчика и получает его условный ключ.

**Blocked by:** 01: Демо-вход и список батчей.

**User Stories:** 46–47, 58, 69–70.

- [x] Административный раздел показывает список заказчиков и форму создания с понятной проверкой имени.
- [x] Созданная организация появляется в списке; условный ключ выдаётся при создании и обозначен как демонстрационный.
- [x] Пользователь может скопировать выданный ключ; ключ не отображается как повторно доступный секрет в обычном списке.
- [x] Заказчик не может открыть административную операцию; отзыв, замена ключа и удаление организации не добавлены.
- [x] Есть состояния ошибки и повтор, ввод не теряется при исправлении.
- [x] Браузерный сценарий проверяет создание и получение условного ключа; проверка формы охватывает обязательное имя и исправление ошибки.

Проверки входят в эту задачу; реализация backend и изменение бизнес-правил не входят.

## Реализация и проверка

Через «Открыть демо команды» доступен раздел `/demo/team/customers`: список организаций, форма с обязательным непустым названием и результат создания. Пробелы по краям убираются при отправке; ограничения длины и уникальности названия не добавлены без требования. Новая организация появляется в общем каталоге и фильтре батчей до перезагрузки страницы. У неё пока нет стримов и батчей.

`CustomersSource` отделяет экран от демонстрационного источника и будущего REST. `DemoOrganizations` хранит общий каталог без ключей. Условный ключ `demo-only-` появляется только в результате создания, явно не подходит для backend и не сохраняется в списке, URL или браузерном хранилище. Копирование показывает подтверждение; при отказе Clipboard API поле остаётся для ручного копирования. Панель не закрывается автоматически, после явного закрытия фокус возвращается к форме.

Выбранный демо-раздел запоминается в `sessionStorage` вкладки. Режим заказчика, в том числе при подмене URL, не открывает операцию; выход сбрасывает выбор. Guard и источник проверяют демо-режим команды; настоящую авторизацию позднее обеспечивает сервер. Замена и отзыв ключа, повторная выдача и удаление организации не добавлены.

Загрузка списка, ошибка и повтор предусмотрены отдельно от создания. Ошибка создания сохраняет введённое название для исправления и повтора; повторное нажатие блокируется на время запроса. Демо-сбой происходит до изменения каталога. Получение результата после потери ответа настоящего сервера требует согласования и записано в плане интеграции.

Добавлены **7 браузерных сценариев**: создание/копирование/переход к батчам, отказ Clipboard API, ошибка списка, ошибка создания с исправлением, запрет операции из режима заказчика, выход из демо команды, клавиатура и узкий экран 390 px. Добавлены **5 проверок компонента формы**: пустое имя, пробелы, исправление с отправкой обрезанного имени, повтор с сохранением ввода, блокировка запроса. Desktop/mobile просмотрены.
