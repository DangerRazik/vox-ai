- [x] Широкая таблица прокручивается, выбор доступен с клавиатуры; браузерный сценарий проверяет несколько колонок и запреты.

Проверки входят в эту задачу; реализация backend и изменение бизнес-правил не входят.

## Реализация и проверка

В меню заказчика доступен раздел `/demo/customer/comparison`. Выбор показывает только завершённые батчи текущего стрима и организации. Нужно не менее двух; число колонок не ограничено двумя. Повторы ID исключены в интерфейсе и демонстрационном источнике, порядок сохраняется; снятие и повторный выбор добавляет батч в конец. Параметры чужой организации в URL не расширяют доступ, недопустимые ID не включаются и объясняются сообщением. Из сводного отчёта можно перейти с заранее выбранным батчем.

`BatchesSource.compareBatches` возвращает опубликованные сводки из того же `DEMO_REPORTS`, что используется отчётами. Добавлен «Батч 01.10» с двумя идеальными звонками, средним 11 и нулём ошибок/нарушений, для демонстрации трёх колонок вместе с существующими батчами 04/02. В таблице показаны средний итог, принятые/успешные записи, отдельные ошибки загрузки/обработки, количество/доля критических нарушений и все 11 исходных средних. `null` остаётся «Нет данных», успешный нулевой итог остаётся числом; исходные оценки не обнуляются вслед за итогом.

Изменение выбора отменяет прежнее чтение и скрывает таблицу, смена стрима также очищает выбор. Стрим без двух завершённых батчей объясняется отдельно. Загрузка списка/сравнения, ошибка и повтор предусмотрены; демонстрационная ошибка сравнения сохраняет выбранные батчи. Dev-сервер проверок использует порт 4300, поскольку 4200 занят другим приложением; `PLAYWRIGHT_PORT` задаёт согласованный порт для baseURL и запуска сервера. Проверки внешних запросов используют адрес из конфигурации.

Добавлены **6 браузерных сценариев**: три колонки и совпадение со сводкой, запреты и повторные ID/выбор, смена стрима с отменой чтения, переход из отчёта, ошибка с повтором без внешних запросов, клавиатура и прокрутка на 390 px. Добавлены **2 проверки компонента таблицы**: `null` против нуля и сохранение исходных оценок, порядок колонок и ссылки на отчёты. Desktop/mobile просмотрены.
