# 01: Демо-вход и список батчей

**Status:** ready-for-agent

**Implementation:** complete (2026-10-06).

**Утверждено:** пользователем 2026-10-06.

**What to build:** Пользователь запускает приложение, выбирает демонстрационный раздел и видит батчи соответствующей организации в рабочем адаптивном интерфейсе.

**Blocked by:** None (can start immediately).

**Этап:** Демонстрационная первая версия.

**User Stories:** 1–4, 14–16, 64–70, 71.

- [x] Локально запускается приложение на проверенной последней стабильной Angular; зависимости закреплены, сборка проходит.
- [x] Есть явно обозначенные демо-входы заказчика и команды. Заказчик попадает на «Батчи», видит организацию, выбранный стрим и согласованное меню.
- [x] Таблица получает данные через заменяемый источник: название, дата, статус, принятые записи и средний итог. До публикации отчёта оценка отсутствует.
- [x] Есть демонстрационные состояния загрузки страницы, пустого списка и ошибки с повтором; административные действия заказчику недоступны.
- [x] Светлое оформление соответствует референсам; меню доступно с клавиатуры и перестраивается на узком экране.
- [x] В браузере проверяются вход, правильная организация, смена стрима, отсутствие промежуточной оценки и повтор после ошибки; приложение не обращается к Whisper, LLM или настоящему backend.

Проверки входят в эту задачу; реализация backend и изменение бизнес-правил не входят.

## Реализация и проверка

Angular 22.2.1, точные версии прямых зависимостей и `package-lock.json`. Данные поступают через `BatchesSource`; демонстрационный источник выделен отдельно от экранов. Неопубликованные оценки скрыты, ноль и отсутствие данных различаются; даты показаны в московском часовом поясе.

Пройдены typecheck, production-сборка, 4 проверки компонента таблицы и 7 браузерных сценариев в Edge через Playwright. Desktop и мобильный экран 390 px просмотрены; таблица прокручивается с клавиатуры, фокус видим.

Code-review относительно согласованного коммита `dc88b80` выполнен по двум осям: Standards и Spec. Единственное замечание обеих проверок — обрезанная рамка фокуса таблицы — исправлено внутренним отступом рамки и проверено в браузере. Основная реализация: `81bb443`.
