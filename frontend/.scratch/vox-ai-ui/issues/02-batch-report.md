# 02: Сводный отчёт завершённого батча

**Status:** ready-for-agent

**Implementation:** complete (2026-10-06).

**Утверждено:** пользователем 2026-10-06.

**What to build:** Заказчик открывает завершённый батч из списка и изучает его сводный отчёт с критериями и таблицей звонков.

**Blocked by:** 01: Демо-вход и список батчей.

**Этап:** Демонстрационная первая версия.

**User Stories:** 17, 23–29, 67.

- [x] Из завершённого батча открывается отчёт с идентификатором стрима, средним итогом из 11, успешными относительно принятых и числом и долей критических нарушений.
- [x] Средние всех 11 критериев отражают исходные оценки; ошибки загрузки и обработки показаны раздельно.
- [x] Таблица звонков показывает исходное имя, необязательного сотрудника, итог либо отсутствие данных и исход обработки.
- [x] Демонстрационная сводка согласована с деталями записей; доля нарушений рассчитывается по успешным, ошибки загрузки не включены в принятые.
- [x] Без успешных записей средние и доля отображаются как «Нет данных», счётчики доступны. До завершения всего батча отчёт недоступен.
- [x] Браузерный сценарий проверяет открытие отчёта, смешанные исходы и отсутствие успешных результатов; компонентные проверки представления показателей различают 0 и отсутствие данных.
- [x] Таблица и показатели доступны на узком экране и с клавиатуры.

Проверки входят в эту задачу; реализация backend и изменение бизнес-правил не входят.

## Реализация и проверка

Отчёт читается через заменяемый `BatchesSource`. Общая оболочка `DemoShell` используется списком и отчётом; организация и стрим сохраняются при возврате и ошибке повторного чтения. Незавершённый батч, чужой и отсутствующий отчёты не раскрывают показатели. Подробный разбор звонка остаётся тикету №03.

Сводка демо подготавливается из тех же записей, которые показаны в таблице: 80 успешных из 90 принятых, сумма итогов 772, средний итог 9,65, 2 критических нарушения (2,5%). Ошибки загрузки — 10, обработки — 10. Исходные оценки критериев сохраняются при нулевом итоге. Второй пример содержит 12 ошибок обработки и ни одного успешного результата; все средние и доля — «Нет данных». Рабочие сводки рассчитывает backend.

Пройдены typecheck, production-сборка, все 15 браузерных сценариев в Edge через Playwright и все 8 проверок компонентов. В №02 добавлены 8 браузерных сценариев и 4 проверки показателей. Просмотрены desktop и мобильный экран 390 px; таблица доступна с клавиатуры и прокручивается внутри страницы.

Code-review относительно согласованного `dc88b80` выполнен по осям Standards и Spec. Standards: 0 замечаний. Spec: потеря организации и контекста возврата после ошибки чтения исправлена и проверена сценарием red → green; оставшихся замечаний нет. Основная реализация: `bb9835f`.
