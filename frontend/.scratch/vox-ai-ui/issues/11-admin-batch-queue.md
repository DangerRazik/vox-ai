# 11: Ручной запуск и отчёты всех организаций

**Status:** ready-for-agent

**Implementation:** complete, 2026-10-07.

**Утверждено:** пользователем 2026-10-06.

**What to build:** Команда фильтрует батчи по организации, ставит готовый батч в очередь и открывает доступные отчёты.

**Blocked by:** 05: Состояние и восстановление батча; 02: Сводный отчёт завершённого батча.

**Этап:** Демонстрационная первая версия.

**User Stories:** 56–58, 13, 21, 69–70.

- [x] В административном списке явно видна организация; фильтр не меняет владельца существующего батча.
- [x] Готовый батч имеет «Поставить в очередь», после действия показывает queued; это доступно и после успешного восстановления.
- [x] Локальная имитация отражает общую FIFO-очередь и последовательную обработку; это не реальный запуск Whisper или LLM.
- [x] Повтор для ожидающего, работающего или завершённого батча возвращает состояние без второго задания.
- [x] Батч с незавершённой загрузкой или общей ошибкой не запускается до подготовки или восстановления.
- [x] Команда открывает завершённые отчёты разных организаций; заказчик по-прежнему не видит кнопку запуска.
- [x] Браузерный сценарий проверяет запуск восстановленного батча, повторный запрос, порядок очереди и переход к отчёту другой организации.

Проверки входят в эту задачу; реализация backend и изменение бизнес-правил не входят.

## Результат реализации

Готовый батч команды запускается из таблицы или сведений; подтверждение содержит владельца и состояние. Повтор уже ожидающего, обрабатываемого или завершённого батча возвращает текущее состояние без нового задания. Неподготовленные состояния отклоняются; восстановленный батч требует нового ручного запуска. Потеря подтверждения после постановки допускает повтор с тем же ID. В режиме заказчика нет запуска или управления очередью, включая прямой административный адрес чтения.

Белая панель общей очереди показывает один активный батч и порядок ожидающих заданий всех организаций независимо от фильтра списка. Явное действие «Имитировать следующий шаг очереди» публикует полный подготовленный отчёт текущего батча и начинает следующий по FIFO. Условные успешные звонки получают 10 из 11; исходные ошибки приёма сохраняются отдельно. Сводный отчёт, разбор звонка и сравнение используют согласованные результаты, настройки берутся из снимка стрима. Удалённый стрим исчезает из ожидающих заданий, остальные продолжают работу. Очередь и новые отчёты существуют только в памяти до перезагрузки; файлы не анализируются, Whisper и LLM не вызываются.

Добавлены **15 браузерных сценариев**: запуск готового и восстановленного батча, общий FIFO и последовательная публикация с другой организацией, три идемпотентных состояния и три запрета, ошибки запуска/чтения и потеря подтверждения, каскад ожидающего задания, права демо-разделов, клавиатура и ширина 390 px. Отдельный сценарий проверяет сохранение ошибки частичного ZIP-приёма в отчёте и сравнении (RED → GREEN). Desktop/mobile просмотрены; обращения к внешним сервисам отсутствуют.
