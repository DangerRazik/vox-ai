# Docker-развёртывание под /vox/

Status: ready-for-human

Подготовить Linux-контейнеры frontend, API и единственного worker для размещения через существующий Nginx на 10.3.237.134:8081/vox/. Сохранить обычный npm start и текущие данные. Ключи не включать в образ; постоянные данные хранить в общем томе.

## Проверки

- Compose validation; сборка обоих образов.
- Компонентные проверки frontend.
- Вход и обновление вложенной страницы /vox/ через браузер.
- Права API/worker на общий том, ffprobe, версия SQLite, сохранность после пересоздания контейнеров.
