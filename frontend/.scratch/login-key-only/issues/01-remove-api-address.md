## Comments

локальное окружение использует прежний `VOX_API_TARGET`/порт 8000.
Проверяем ранее согласованные границы: DOM входа и браузерный REST API.


Проверено: `npm run typecheck`, `npm run build`; 67 компонентных проверок;
полный Playwright — 132 passed, 3 opt-in live skipped. В набор вошла живая
REST-проверка входа двух заказчиков/команды, обновления страницы, выхода и
изоляции через браузерный прокси. Стенд использовал временные SQLite/файлы
и тестовые ключи; Whisper/LLM и постоянная БД пользователя не использовались.

Ручной просмотр: форма больше не принимает адрес, запросы и восстановление
подключения используют API текущего сайта; старый другой адрес не получает ключ.
