# Аналитика обработанного батча

Status: ready-for-agent
Implementation: complete

Запрос: показать в UI расход токенов Whisper и LLM, общую длительность записей, время обработки и основной коэффициент длительность/время. Пользователь выбрал исключение очереди и ручных пауз.

Реализация: collector usage на границах запросов; LLM включает разметку ролей и оценку; активное время perf_counter минус паузы; атомарное сохранение в summary. UI «Производительность обработки» с коэффициентом, длительностями и расходом, включая честное отсутствие/частичность статистики. Исторические записи не пересчитывают оценки и не получают выдуманные токены.

Проверено: 36 backend-тестов, 80 frontend-тестов, 13 браузерных сценариев отчёта/прогресса, production build /vox/, desktop/mobile screenshots и подсказка LLM без горизонтального переполнения. Новые реальные вызовы платных моделей для тестов не выполнялись.
