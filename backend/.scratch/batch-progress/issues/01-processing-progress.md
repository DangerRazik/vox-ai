# Прогресс обработки

Status: ready-for-agent
Implementation: complete

По запросу пользователя добавлена полоса реального операционного прогресса на страницу состояния батча. Backend сохраняет число завершённых попыток обработки, frontend обновляет данные каждые 5 секунд только в состояниях queued/processing. При сбое чтения сохраняются последние данные с пояснением. Последний звонок отображает 99% и сохранение результатов, completed — 100% и переход к отчёту. Сохранение аналитики осталось атомарным (ADR-0003, дополнение ADR-0006).

Проверки: миграция существующей БД, сброс новой попытки, счётчик ошибок, отсутствие частичных результатов, компоненты и браузерный переход queued → processing → completed со сбоем чтения.


Пользователь дополнительно запросил паузу. Добавлены административные pause/resume с ожиданием текущего звонка, хранением текущих исходов в памяти worker и блокировкой общей очереди. После перезапуска действует прежнее восстановление всего батча. Проверены права, повтор команд, отсутствие повторной обработки после продолжения и атомарная публикация.
