# 03: Создание заказчика и доступ по API-ключу

**What to build:** Команда Vox AI создаёт организацию и выдаёт ключ; заказчик обращается к backend только в пределах своей организации.

**Blocked by:** 01 — Согласовать техническую основу backend.

Status: ready-for-agent
Resolution: completed

- [x] Административный запрос создаёт заказчика и выдаёт его API-ключ; данные организации сохраняются после перезапуска.
- [x] Ключ заказчика определяет владельца на сервере; переданный клиентом идентификатор другой организации не расширяет доступ.
- [x] Отсутствующий или неверный ключ отклоняется, административные операции недоступны ключу заказчика.
- [x] Через доступный внешний API проверить изоляцию двух организаций и административное чтение; пустые списки ресурсов собственной организации также доступны.
- [x] Секреты не попадают в обычные ответы, логи и сообщения об ошибках; способ хранения соответствует подтверждённому техническому проекту.
- [x] Пользовательские аккаунты, дополнительные роли и отзыв/замена ключей не добавляются.
- [x] Проверки выполняются с реальной изолированной БД. Сценарии авторизации не вызывают модели искусственно.
