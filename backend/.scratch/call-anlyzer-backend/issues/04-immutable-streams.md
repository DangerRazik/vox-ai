# 04: Создание и выбор неизменяемого стрима

**What to build:** Команда создаёт стрим заказчика с фиксированными параметрами и материалами; заказчик получает и выбирает только доступные ему готовые стримы.

**Blocked by:** 02 — Передавать настройки выбранного стрима в обработчик звонка; 03 — Создание заказчика и доступ по API-ключу.

Status: ready-for-agent

Resolution: completed

- [x] Административный API создаёт стрим с промптами, моделями, опциями коррекции, нежелательных выражений и темпа, базой знаний и флагом обнуления итога при нарушении.
- [x] Включённые словарные опции требуют соответствующих корректных материалов; неполный стрим не становится пригодным для обработки.
- [x] Заказчик через API видит свои стримы, их идентификаторы и публичные параметры; полные материалы и сервисные секреты не раскрываются обычным чтением.
- [x] Изменение параметров или содержимого материалов создаёт новый идентификатор; ранее сохранённые настройки и файлы не перезаписываются согласно ADR-0001.
- [x] После рестарта сохраняются принадлежность стрима и его контекст; глобальные настройки не переключаются между организациями.
- [x] Проверить создание двух разных стримов, изоляцию организаций и неизменяемость сохранённых материалов через API с реальными БД/файлами.

## Comments

Реализованы multipart API, отдельные каталоги материалов, снимок SQLite,
проверка SHA-256 и восстановление контекста. Подробности: docs/stream-api.md.
Проверки используют реальные временные БД/файлы; модели не вызываются.
Бизнес-семантика новых опций и привязка батча остаются задачей 05.
