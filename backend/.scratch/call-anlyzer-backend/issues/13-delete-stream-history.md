# 13: Удаление стрима вместе с его историей

**What to build:** Команда Vox AI явно удаляет стрим, его очередь, записи, результаты и материалы, не затрагивая данные других стримов или заказчиков.

**Blocked by:** 08 — Устойчивая общая очередь и защита от повторного запуска; 10 — Восстановление очистки после файловых сбоев.

Status: ready-for-human

- [x] Удаление доступно только административному ключу; удаляются стрим и связанные батчи, загрузочные метаданные, попытки, очередь, транскрипции, оценки и отчёты.
- [x] Материалы и оставшиеся управляемые входы очищаются устойчиво; сбой после удаления данных не теряет задачу файловой очистки.
- [x] Проверить конфликт активного приёма/обработки и атомарность относительно захвата очереди: удалённый стрим не может начать обработку. Поведение соответствует подтверждённому техническому проекту.
- [x] Сразу после удаления ресурсы недоступны через API. Данные других стримов и сам заказчик сохраняются.
- [x] Повтор очистки безопасен и не вызывает модели; история не удаляется автоматически по таймеру.
- [x] Проверить удаление ожидающего и завершённого стрима, сохранность соседнего стрима, гонку запуска и сбой очистки на реальных БД/файлах; для анализируемых записей использовать реальные модели.

### Реализация и приёмка — 2026-10-07

завершены. Добавлен административный DELETE /v1/admin/streams/{stream_id}:
204 при удалении, 403 для заказчика, 404 для отсутствующего ресурса,

одной BEGIN IMMEDIATE транзакцией, сериализованной относительно claim/start.

пять секунд между батчами, без моделей. Ошибки не раскрывают системные пути.

по явно созданным заданиям, не историю. API сразу возвращает 404 удалённым ресурсам.
