# 07: Импорт ZIP-архива

**What to build:** Пользователь передаёт ZIP через API для frontend; архив формирует один батч выбранного стрима и автоматически завершает загрузку при наличии принятых записей.

**Blocked by:** 06 — Массовая API-загрузка с частичным приёмом.

Status: ready-for-human
Implementation: completed
Resolution: completed

- [x] Поддержать ZIP без пароля с обычными подпапками; другие архивы, зашифрованный, пустой или нераспаковываемый архив получают понятную ошибку загрузки.
- [x] Распаковка не позволяет выходить за управляемый каталог или перезаписывать сторонние файлы; небезопасные элементы отклоняются.
- [x] Корректные записи распаковываемого архива принимаются несмотря на ошибки остальных файлов; ошибки доступны пользователю по элементам архива.
- [x] При наличии принятой записи состав фиксируется автоматически и батч готов к ручному запуску. При нуле принятых записей запуск запрещён.
- [x] Использовать правила идентификатора загрузки и дедупликации; повтор архива не создаёт независимый батч или лишние счётчики.
- [x] Живой сценарий ZIP → запуск → отчёт использует реальные модели. После фиксации удалить архив и извлечённые входы, сохранив историю и материалы стрима.
- [x] Проверки импорта не требуют реализации frontend в этом репозитории.

## Comments

### 2026-10-07 — реализация

Изменения только в backend. Добавлены `POST /v1/batch-archives`, частичный импорт,
отказы по небезопасным/повреждённым элементам, необязательный JSON метаданных,
идемпотентность при перепаковке и удаление ZIP после публикации.
Формат запроса проверен по подготовленному frontend; сопоставление ответа для
будущего REST-адаптера описано в `docs/archive-api.md`.

Обычная suite: 40 тестов прошли, 4 opt-in пропущены. Контекст: 3 прошли, 1 opt-in
пропущен. `compileall`, `pip check` и `git diff --check` прошли. Проверки ZIP
используют публичный REST и реальные временные БД/архивы, внешний ffprobe
контролируется на границе процесса. Живая ZIP-приёмка с настоящим HTTP и моделями
подготовлена в `tests/test_live_archive.py`; окончательный результат и ревью
будут записаны после завершения.
