# 02: Передавать настройки выбранного стрима в обработчик звонка

**What to build:** Обработчик получает конкретные настройки и материалы стрима явно, не переключая общие настройки приложения между звонками; существующий CLI продолжает работать.

**Blocked by:** None (can start immediately).

Status: ready-for-agent
Resolution: completed

- [x] Добавить явную передачу контекста обработки через существующие этапы: транскрибация, назначение ролей, метрики, база знаний и оценка.
- [x] Модели и влияющие на анализ параметры брать из переданного контекста; адреса сервисов и секретные API-ключи оставить операционной конфигурацией, не включать в публичный контекст.
- [x] Сохранить текущий порядок алгоритмов и формат результата; это подготовка интерфейсов, а не реализация хранения стримов или всех отсутствующих опций.
- [x] Сохранить текущий способ запуска CLI и совместимое поведение для существующей конфигурации по умолчанию.
- [x] Проверить последовательно два разных контекста и повтор первого: параметры одного не изменяют другой и не требуют изменения общих настроек между запусками.
- [x] Проверку обработки провести с реальными Whisper/LLM на разрешённых аудио, без подмены ответов. Проверять структуру и выбранный контекст, а не идентичность текста модели.
- [x] Зафиксировать результат живой проверки либо конкретную причину невозможности её выполнения; не объявлять недоступный сервис успешной проверкой.
