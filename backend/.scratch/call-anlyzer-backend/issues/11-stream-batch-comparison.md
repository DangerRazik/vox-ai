# 11: Сравнение завершённых батчей одного стрима

**What to build:** Руководитель через API сравнивает показатели выбранных завершённых батчей одного стрима, полученные из сохранённых результатов без нового анализа.

**Blocked by:** 06 — Массовая API-загрузка с частичным приёмом.

Status: ready-for-human
Implementation: completed
Resolution: completed

- [x] API принимает выбранные идентификаторы батчей и возвращает показатели каждого с принадлежностью одному стриму.
- [x] Проверять доступ организации, завершённость и принадлежность стриму; чужие, удалённые, незавершённые или относящиеся к другому стриму батчи не смешиваются.
- [x] Возвращать счётчики записей/ошибок, средний итог из 11, средние 11 исходных критериев, число и долю критических нарушений.
- [x] Использовать только опубликованные данные БД и сохранить «нет данных». Повтор выбранного идентификатора не удваивает батч.
- [x] Сравнение не вызывает Whisper/LLM и не меняет сохранённые оценки.
- [x] Подготовить минимум два батча реальным анализом, затем через API сверить сравнение с их отчётами, проверить изоляцию и доступ после рестарта и удаления входных аудио.
