# Vox AI

Система анализа звонков колл-центра для оценки работы сотрудника по заданным критериям.

## Язык предметной области

**Заказчик**:
Организация, использующая Vox AI для анализа звонков своих сотрудников. Её записи, сотрудники и отчёты отделены от данных других заказчиков.
_Не использовать_: клиент (для организации-заказчика).

**Команда Vox AI**:
Команда, которая в тестовой версии создаёт и настраивает стримы для заказчиков и вручную запускает обработку батчей.

**Пользователь заказчика**:
Представитель организации-заказчика, который загружает записи, выбирает готовый стрим и просматривает отчёты своей организации.

**Запись звонка**:
Аудиозапись разговора, поступающая в систему для анализа.

**Ошибка загрузки**:
Причина, по которой переданный файл не принят как запись звонка, например повреждение или неподдерживаемый формат файла.

**Ошибка обработки записи**:
Неуспешное выполнение стрима для принятой записи звонка.

**Ошибка обработки батча**:
Сбой, препятствующий завершению обработки всего батча или целостному сохранению его результатов.

**Архив записей**:
Файл архива, содержащий отдельные аудиозаписи звонков и передаваемый пользователем для загрузки в систему.

**Стрим**:
Последовательность транскрибации записи звонка, обработки транскрипции и анализа результатов с фиксированными настройками, словарями и базой знаний. Принадлежит заказчику; любые изменения означают стрим с новым идентификатором.

**История результатов стрима**:
Сохранённые данные о звонках и результатах завершённых батчей одного стрима, используемые для сравнения показателей разных батчей этого стрима. Сохраняется до удаления стрима и удаляется вместе с ним.

**Удаление стрима**:
Удаление стрима вместе с принадлежащими ему батчами, записями и сохранённой историей результатов.

**Сравнение батчей**:
Сопоставление показателей нескольких выбранных завершённых батчей одного стрима.

**Батч**:
Группа принятых записей звонков в рамках одной загрузки, связанная с одним заказчиком и одним стримом. После завершения загрузки состав группы неизменяем. Результаты обработки батча рассматриваются совместно и сравниваются с результатами других батчей этого стрима.

**Статус батча**:
Состояние батча, отражающее ход загрузки, ожидание запуска и обработки либо завершение.

**Идентификатор загрузки**:
Обозначение исходной загрузки, сохраняемое при её повторе после сбоя. Новый идентификатор обозначает независимую загрузку и новый батч.

**Дубликат файла**:
Файл с содержимым, совпадающим с уже принятой аудиозаписью того же батча. Внутри батча соответствует существующей записи.

**Словарь нежелательных выражений**:
Набор слов и выражений, присутствие которых требуется выявлять в транскрипции.

**Словарь корректировки**:
Словарь, используемый для исправления текста транскрипции и предоставляемый в виде файла.

**База знаний**:
Справочные материалы, на которые можно опираться при оценке разговора.

**Сотрудник**:
Участник разговора, представляющий колл-центр, работу которого оценивает система.

**Клиент**:
Участник разговора, общающийся с сотрудником колл-центра.

**Транскрипция**:
Текст разговора, полученный из записи звонка и представленный репликами с временными границами и идентификаторами говорящих. Для анализа реплики распределяются между ролями сотрудника и клиента.

**Реплика**:
Фрагмент транскрипции, произнесённый одним говорящим, с текстом, временем начала и окончания в записи и идентификатором этого говорящего.

**Критерий оценки**:
Заданное требование к работе сотрудника, по которому оценивается разговор. При создании стрима выбирается непустой набор из 11 доступных критериев; набор фиксируется под ID стрима. Отключённые критерии не оцениваются и не входят в итог.

**Оценка критерия**:
Числовая оценка работы сотрудника по одному критерию стрима: 0 — критерий не выполнен, 0.5 — выполнен частично, 1 — выполнен полностью. Для неприменимого критерия используется 1 по умолчанию с указанием неприменимости в пояснении.

**Критерий «Критическое нарушение»**:
Критерий оценки с бинарным результатом: 0 — нарушение есть, 1 — нарушений нет. Наличие нарушения обнуляет итоговую оценку звонка, если в стриме включено соответствующее правило.

**Итоговая оценка звонка**:
Сумма оценок выбранных критериев, представленная как «<оценка> из <число выбранных критериев>». При выявленном критическом нарушении становится 0, если критерий 5.2 и правило обнуления включены в стриме. Старые стримы используют все 11 критериев.

**Результат оценки**:
Структурированный набор оценок работы сотрудника по всем критериям стрима на основе разговора. По каждому критерию содержит его идентификатор, оценку и пояснение.

**Метрика звонка**:
Показатель, полученный при анализе записи или транскрипции звонка.

**Отчёт**:
Представление результатов анализа, которое руководитель изучает для подготовки обратной связи сотруднику. В Vox AI предусмотрены отчёты по отдельным звонкам и сводные отчёты по батчам.

**Отчёт по звонку**:
Подробное представление результатов анализа одной записи звонка по выбранному стриму.

**Сводный отчёт по батчу**:
Итоговое представление результатов анализа записей одного батча после завершения их обработки. Используется для изучения группы звонков и сравнения батчей одного стрима.

**Руководитель**:
Пользователь отчёта, который изучает результаты анализа и даёт сотруднику обратную связь.

**Обратная связь**:
Комментарии руководителя сотруднику по результатам изучения отчёта.
