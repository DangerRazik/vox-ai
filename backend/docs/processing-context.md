# Явный контекст обработки звонка

Задача №02 сохраняет порядок pipeline и формат результата. Стримы, их хранение,
новые переключатели этапов и правила канонизации оценок здесь не реализуются.

## Интерфейс

Существующий вызов `process_call(audio_path, kb_path)` и аргументы CLI сохранены.
Он создаёт снимок аналитических настроек через `ProcessingContext.from_defaults`.
Для выбранного стрима используется `process_call(audio_path, context=context)`.
Одновременная передача `kb_path` и `context` отклоняется до обращения к сервисам.

`ProcessingContext` содержит путь базы знаний, модели Whisper/LLM, язык,
промпт Whisper, шаблон назначения ролей, системный и пользовательский промпты
оценки, пороги пауз/перебиваний и словарь коррекции. Шаблон ролей принимает
`{fragments}`, шаблон оценки — `{checklist}`, `{kb}`, `{metrics}`, `{dialog}`;
литеральные фигурные скобки JSON экранируются удвоением.

Контекст — frozen dataclass; словарь копируется и защищается MappingProxyType.
`dataclasses.replace` создаёт отдельный вариант контекста. При явном контексте
этапы не читают модели, промпты, словари или пороги из глобальных settings.
Адреса Whisper/LLM и API-ключи остаются операционной конфигурацией.
Канонический чек-лист и существующие алгоритмы не меняются.

Путь базы знаний не делает сам файл неизменяемым: неизменяемое хранение
материалов относится к задаче №04. Здесь pipeline читает именно файл контекста
на прежнем этапе загрузки KB.

## Проверка

Локально: `.venv\Scripts\python.exe -m unittest discover -v`.
Живой тест включается явно переменной `RUN_LIVE_CONTEXT_TEST=1` и командой
`.venv\Scripts\python.exe -m unittest test_processing_context.LiveProcessingContextTests -v`.
Тест обращается к реальным Whisper/LLM, может быть платным и требует `.env`
и разрешённой записи `call_002.mp3`. Подмены ответов нет.

Тест выполняет A → B → A: разные словари, базы знаний, пороги и промпты,
проверяет маркеры коррекции, структуру результата, метрики и отсутствие
изменения settings. Модели в обоих контекстах используют доступные настроенные
идентификаторы; переключение между разными серверами не проверяется и не входит
в контекст. Точное совпадение текстов или оценок моделей не требуется.

Временные базы знаний удаляются автоматически; исходное аудио не меняется.
Журналы и результаты ручного CLI-прогона остаются вне репозитория во временном
каталоге. Статический анализ типов не запускался: mypy/pyright не установлены;
compileall проверяет только синтаксис, а не типы.
