# Неизменяемые стримы: реализованный API (задача 04)

Запуск и окружение: [customer-api.md](customer-api.md).
`VOX_MATERIALS_ROOT` задаёт каталог материалов (default `data/streams`).
API и будущий worker должны использовать одинаковые абсолютные пути БД и материалов.

## Создание

Обновление 2026-10-09: `config.enabled_criteria` выбирает непустой набор уникальных ID
из 11 критериев. Отсутствие поля означает все 11. Отключённые критерии исключаются
из чек-листа, результатов и максимума; `max_total` равен количеству выбранных.
Публичное поле `criteria` содержит выбранные критерии. Старые снимки сохраняют
прежний набор. См. [ADR 0005](adr/0005-selected-stream-criteria.md).

`POST /v1/admin/customers/{customer_id}/streams` требует административный Bearer-ключ.
Multipart: JSON-строка `config`, обязательный файл `knowledge_base`, необязательные
файлы `text_corrections` и `unwanted_expressions`. Ответ 201 — полный снимок
настроек и метаданные материалов (SHA-256 и размер).

Поля конфигурации:

- `name`;
- `whisper_prompt`: если отсутствует, берётся `settings.WHISPER_PROMPT` из `config.py`; явная пустая строка отключает подсказку;
- `long_pause_sec` (2.0), `interruption_gap_sec` (0.2), неотрицательные;
- `text_correction_enabled`, `unwanted_expressions_enabled` (false);
- `speech_rate_enabled`, `zero_total_on_critical` (true).

С 2026-10-08 сайт не передаёт модели, язык, промпт распределения ролей и два
промпта LLM. Backend заполняет отсутствующие `whisper_model`, `llm_model`,
`speech_lang` из `config.settings` (`WHISPER_MODEL`, `GPL_MODEL`, `SPEECH_LANG`),
`role_prompt` из `transcriber._ROLE_PROMPT`, `analysis_system_prompt` и
`analysis_user_prompt` из `analyzer.SYSTEM` / `USER_TMPL`. Эти значения вместе
с редактируемыми настройками сохраняются в полном неизменяемом снимке.
Уже созданные стримы не перечитывают новые значения по умолчанию при обработке.
Для совместимости полные конфигурации прежних API-клиентов всё ещё принимаются;
если значение явно передано, оно валидируется и сохраняется, а не заменяется.

`GET /v1/admin/stream-defaults` требует административный ключ и возвращает только
`{"whisper_prompt": "исходная подсказка"}` для заполнения формы нового стрима.
Ключи и адреса провайдеров не передаются. Запрос не вызывает модели.
Сервер должен иметь настроенную Python-конфигурацию обработки; сервисные
переменные окружения описаны в [worker.md](worker.md).

Промпт ролей содержит `{fragments}`; пользовательский промпт оценки — все
`{checklist}`, `{kb}`, `{metrics}`, `{dialog}`. Другие подстановки и форматирование
запрещены. Литеральные скобки экранируются `{{` и `}}`.
Сервисные адреса и ключи не входят в стрим; неизвестные поля отклоняются.

База знаний — непустой UTF-8 текст, включая поддерживаемый текущим reader
HTML/quoted-printable; бинарный Word `.doc` не поддерживается.
Словарь коррекции — непустой JSON-объект строка → строка без повторных ключей.
Нежелательные выражения — непустой JSON-массив непустых строк.
Включённая словарная опция требует файл; переданный файл проверяется также при
отключённой опции. Ошибочные запросы — 422 без отражения материалов;
несуществующий заказчик — 404, неадминистративный ключ — 403.

## Чтение и выбор

- `GET /v1/streams`: доступные стримы; административный фильтр `customer_id`.
- `GET /v1/streams/{stream_id}`: идентификаторы, имя, дата, модели, язык,
  четыре опции, ID и названия выбранных критериев; без промптов, словарей и путей.
- `GET /v1/admin/streams/{stream_id}`: полный снимок и метаданные материалов.

Чужой стрим и попытка расширить доступ фильтром возвращают 404.
Внутренний `StreamStore.load_context(stream_id, customer_id)` проверяет владельца
и SHA-256 всех файлов и восстанавливает ProcessingContext без переключения
глобальных настроек. Привязка к батчу относится к задаче 05.

## Неизменяемость и границы

Каждое создание получает новый UUID и отдельный каталог; имена загружаемых файлов
не используются для путей хранения. Файлы записываются до публикации записи БД.
Ошибка создания удаляет каталог; авария процесса до commit может оставить
неопубликованный каталог (автоматическая очистка сирот здесь не реализована).
Обновление снимка запрещено триггером SQLite; API редактирования нет.
SHA-256 обнаруживает внешнюю порчу при загрузке контекста, но не заменяет права
файловой системы: каталог должен быть доступен только сервису.

Опции сохранены в контексте; новые алгоритмы и правила оценки относятся к задаче 05.
Whisper/LLM в задаче 04 не вызываются.

## Проверки

`python -m unittest tests.test_stream_api -v` — реальные временные SQLite/файлы:
создание, восстановление после пересоздания приложения, изоляция, новый ID,
сохранность старых материалов, отсутствие редактирования, порча файлов и валидация.
`python -m unittest discover -s tests -v` — регрессия API заказчиков и стримов.
