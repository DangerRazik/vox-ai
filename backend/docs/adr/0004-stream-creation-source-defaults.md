# 0004: Исходные настройки обработки для формы стрима

Принято: 2026-10-08, по запросу пользователя. Уточняет доступные настройки
формы, сохраняя [неизменяемость стрима](0001-immutable-streams.md).

Сайт скрывает модель Whisper, язык, промпт распределения ролей, модель LLM
и оба промпта анализа. При создании через сайт эти значения берутся сервером
из действующих `config.py`, `transcriber.py` и `analyzer.py`. Frontend не хранит
копии исходных промптов и не отправляет скрытые поля, включая при создании
на основе старого стрима. Полный API-конфиг прежних клиентов поддерживается
для совместимости, его явно заданные поля по-прежнему валидируются.

Промпт Whisper загружается из `settings.WHISPER_PROMPT` и остаётся редактируемым.
При создании на основе стрима форма переносит его прежний Whisper-промпт,
опции и числовые пороги. Материалы выбирают заново. Создание даёт новый ID.

Все итоговые настройки сохраняются в снимке в момент создания. Изменение
исходных значений в коде или окружении действует на последующие создания,
а существующие стримы и их результаты остаются связаны с прежними настройками.

Источник Whisper для формы — административный `GET /v1/admin/stream-defaults`.
Он отдаёт только текст подсказки; ключи и адреса провайдеров в ответ не входят.
При ошибке загрузки сайт предлагает повторить и не подставляет демо-значения.
