# Выбор критериев оценки в стриме

Решение пользователя от 2026-10-09 заменяет правило обязательного набора из 11
критериев из ADR 0002: при создании стрима команда выбирает непустое подмножество
существующих 11 критериев. По умолчанию включены все. Набор входит в неизменяемый
снимок; его изменение создаёт новый стрим. Старые снимки без `enabled_criteria`
продолжают использовать все 11 критериев, опубликованные результаты не пересчитываются.

В запрос LLM передаётся только выбранный чек-лист. Backend проверяет оценки выбранных
критериев, игнорирует лишние и рассчитывает сумму и `max_total` по выбранному набору.
Отключённые критерии отсутствуют в результатах и средних оценках. Максимум равен
числу выбранных критериев, например 8. Неприменимый выбранный критерий по-прежнему
получает 1 с пояснением. Для выбранного 5.2 сохраняется бинарная оценка 0/1;
его отключение исключает проверку критического нарушения и обнуление итога.

Сводки и сравнение используют сохранённый `max_total` и средние только выбранных
критериев. Батчи разных стримов по-прежнему не смешиваются.
