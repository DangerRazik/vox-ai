# Результаты батча публикуются целиком

Пользователь выбрал сохранение аналитических результатов только после обработки батча вместо сохранения каждого готового звонка. Поэтому все исходы записей, оценки, итоговый отчёт и завершение батча фиксируются целиком: при ошибке сохранения ни один новый аналитический результат батча не остаётся в БД. Загрузочная метаинформация и очередь сохраняются раньше, чтобы переживать перезапуск.

Прерванная обработка не имеет сохранённого аналитического прогресса отдельных звонков. Ошибочный батч восстанавливается повторной загрузкой с прежним идентификатором и ручным запуском всего батча. Идентификатор исходной загрузки защищает от повторной публикации, в том числе при потере подтверждения уже успешного commit. Независимая новая загрузка того же файла в другой батч допускает отдельный новый анализ.

Входные файлы удаляются сразу после успешной фиксации результатов; при ошибке всего батча сохраняются до восстановления. Очистка не может откатить опубликованные результаты и повторяется отдельно при техническом сбое. История результатов в БД сохраняется до явного удаления стрима.
