# Операционный прогресс обработки батча

Статус: принято по запросу пользователя 13.10.2026.

В batches сохраняется processed_calls: число законченных попыток обработки звонков, включая ошибки отдельных записей. Счётчик обновляется короткой транзакцией после каждого звонка, сбрасывается перед новой постановкой в очередь и не используется для продолжения анализа после сбоя.

Это дополняет ADR-0003: результаты, оценки и итоговый отчёт по-прежнему фиксируются одной транзакцией после всего батча. Счётчик не содержит аналитических данных. До публикации интерфейс не показывает 100%: после последней записи отображает сохранение результатов. GET /v1/batches/{id} возвращает processing_progress с processed_calls и total_calls с прежними ограничениями доступа.


## Пауза

Администратор может запросить паузу через POST `/v1/admin/batches/{id}/pause` и продолжение через POST `/v1/admin/batches/{id}/resume`. Текущий звонок не прерывается. Worker подтверждает паузу на границе звонков, сохраняет промежуточные исходы только в памяти и удерживает эксклюзивность общей очереди. GET возвращает `pause_requested` и `paused` внутри processing_progress; основной статус остаётся processing, поэтому сохраняются ограничения удаления/восстановления занятого батча.

Смена состояния управляется короткой транзакцией; во время ожидания транзакции не удерживаются. Повтор команд идемпотентен для активного батча. После перезапуска worker прерванный батч становится batch_failed согласно ADR-0003. Пауза не вводит долговременное сохранение промежуточной аналитики и не позволяет продолжать анализ после перезапуска процесса.
