# Аналитика ресурсов и скорости батча

Статус: принято 13.10.2026 по запросу пользователя.

В опубликованный summary батча добавляется processing_analytics. Учёт расхода собирает только числовые значения usage ответов транскрибации, LLM-разметки ролей и LLM-оценки. Параметры запросов, ключи и содержимое ответов в учёт не входят. Общий расход LLM суммирует роли и оценку; израсходованные токены учитываются и для записей, закончившихся ошибкой после ответа сервиса. Скрытые внутренние повторы SDK не имеют отдельной статистики usage.

Отсутствующий расход не считается нулём. total_tokens=null означает неполную статистику, reported_tokens — сумму полученных значений, unreported_requests — число запросов без данных о токенах. Формат транскрибации может отдавать duration вместо токенов: это не преобразуется в фиктивные токены. Нулевой расход означает отсутствие запросов к данному сервису либо явно сообщённые нулевые токены.

Главный показатель speed_ratio = total_audio_seconds / active_duration_seconds. Длительность аудио суммируется по уникальным принятым calls, включая ошибки обработки. Активное время измеряется perf_counter с момента начала исполнения батча до подготовки публикации, без ожидания очереди и подтверждённых ручных пауз. calls_duration_seconds хранит сумму времени исполнения process_call, pause_duration_seconds — фактическое ожидание ручных пауз. Очередь и паузы исключаются по явному решению пользователя.

Это аналитика последней завершённой попытки обработки. При прерывании всего батча до публикации исходы и ресурсная статистика этой попытки не сохраняются; восстановление запускает новую попытку согласно ADR-0003. Новый блок не обещает полный биллинговый аудит всех неудачных/прерванных попыток и повторов провайдера.

Ресурсная аналитика сохраняется в одном commit с исходами записей и итоговым отчётом. Отдельных таблиц и миграции ресурсоучёта нет. Для старых summary чтение восстанавливает только общую длительность из calls, остальные ранее не сохранённые поля остаются null. Старые результаты и исходные оценки не меняются.
