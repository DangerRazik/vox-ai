# Неприменимый критерий получает оценку 1

Правило обязательных 11 критериев и постоянного максимума ниже заменено
[ADR 0005](0005-selected-stream-criteria.md). Правило оценки неприменимого выбранного
критерия остаётся действующим.

Для сравнения результатов звонков и батчей стрим содержит фиксированный набор из 11 критериев. Поэтому результат содержит все 11 критериев: неприменимый к разговору критерий получает 1 по умолчанию с явным указанием неприменимости в пояснении и участвует в исходной сумме с максимумом 11 баллов. Оценка 1 может означать как полное выполнение, так и неприменимость; различие определяется пояснением, отдельный статус «неприменим» не используется. Правило обнуления итоговой оценки при критическом нарушении применяется отдельно согласно настройкам стрима.
